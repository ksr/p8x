# cf-card -- KiCad

Generated by `generators/gen_kicad.py` from the canonical gen_eagle netlist
(`CARDS["cf-card"]`), same standard as the memory card: 4-layer (F/B signals,
In1=GND, In2=VCC planes), a bypass cap above each IC, a labelled LED/jumper bank,
part values on silk. Routed with Freerouting. GENERATORS ARE CANON -- edit
`gen_kicad.py` and re-run `generators/build_kicad_card.sh cf-card`.

| File | What |
|------|------|
| `p8x-cf-card.kicad_pcb` | the board |
| `p8x-cf-card.ses` | the Freerouting routing |
| `p8x-cf-card-gerbers.zip` | orderable gerbers |
| `p8x-cf-card-placement.pdf` | parts placement (refs+values) |
| `p8x-cf-card-render-top.png` / `-3d.png` | renders |

Exotic parts use the closest standard KiCad footprint (flagged when built).
