# XOR Trial Board — KiCad

The [XOR trial circuit](../README.md) realised as an orderable **KiCad 10** PCB,
generated by a script (generators are canon here too — edit `gen_xor.py`, re-run,
don't hand-edit the `.kicad_pcb`). 62 × 44 mm, 2-layer, all through-hole.

| File | What it is |
|------|-----------|
| `gen_xor.py` | the generator — builds the board with `pcbnew`: footprints, nets, routing, a bottom-layer GND pour, and the Edge.Cuts outline |
| `xor_trial.kicad_pcb` | the generated board (open it in KiCad Pcbnew) |
| `xor_trial.kicad_pro` | project file so it opens as a project |
| `xor_trial_gerbers.zip` | **the orderable output** — Gerbers + Excellon drill |

## Regenerate

KiCad's own Python has `pcbnew`, so use it (not the system python):

```sh
PYK=/Applications/KiCad/KiCad.app/Contents/Frameworks/Python.framework/Versions/3.9/bin/python3
"$PYK" hardware/xor-trial/kicad/gen_xor.py
```

## Check + export (kicad-cli)

```sh
CLI=/Applications/KiCad/KiCad.app/Contents/MacOS/kicad-cli
"$CLI" pcb drc xor_trial.kicad_pcb                       # 0 violations, 0 unconnected
"$CLI" pcb export gerbers --no-protel-ext -o gerbers/ xor_trial.kicad_pcb
"$CLI" pcb export drill --format excellon --excellon-units mm -o gerbers/ xor_trial.kicad_pcb
( cd gerbers && zip ../xor_trial_gerbers.zip *.gbr *.gbrjob *.drl )
```

The committed board passes DRC clean (0 violations, 0 unconnected).

## How it's routed

- **GND** is a **bottom-layer copper pour**. Every part here is through-hole, so
  its pads penetrate the bottom layer and connect to the pour automatically — no
  GND tracks to draw.
- **VCC** runs on the top layer: up from J1, across the top through both buttons'
  top pads, with branches down to U1 pin 14 and to C1.
- The **signal** nets (`N1A`, `N1B`, `N1Y`, `NLED`) route on top where they can;
  `N1B` and `N1Y` take a short **bottom** hop (again via the THT pads, no vias) to
  reach U1's left-hand pins without crossing anything or skimming a GND pad.

## Order it

Upload **`xor_trial_gerbers.zip`** to any fab (JLCPCB / PCBWay / OSHPark — all take
this Gerber+drill set). Defaults are fine: 2-layer, 1.6 mm FR4, HASL. Then stuff it
with the [BOM in the parent README](../README.md#bill-of-materials) — all common
through-hole parts.

> This is the first board taken through **KiCad** (the rest of the machine uses the
> Eagle flow in `generators/gen_eagle.py`). It's a trial of that toolchain on a
> deliberately tiny circuit; the pcbnew-generator approach mirrors the "generators
> are canon" rule the Eagle boards follow.
