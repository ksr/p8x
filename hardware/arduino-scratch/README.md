# Breadboard Arduino (ATmega328P) — workflow test board

**Not part of the P8X machine.** A small standalone board generated to exercise
the Cowork → Fusion round-trip: generate the Eagle `.sch`/`.brd` here, open in
Fusion, place + route, and back. Classic "Arduino from scratch" recipe, all
through-hole.

Generated by [`generators/gen_arduino.py`](../../generators/gen_arduino.py)
(standalone — reuses gen_eagle's emitters but not `card()`, since this board has
no P8X bus connector). Regenerate:

```sh
python3 generators/gen_arduino.py
```

Parts are parked off the board outline (unplaced) with the ratsnest — place and
route in Fusion.

## Circuit

| Ref | Part | Role |
|-----|------|------|
| U1 | ATmega328P-PU (DIP-28) | the MCU |
| U2 | 7805 (TO-220) | 5 V regulator |
| Y1 | 16 MHz crystal (HC-49) | clock |
| C1, C2 | 22 pF | crystal load caps |
| C3, C4 | 100 nF | VCC / AVCC decoupling |
| C5 | 100 nF | DTR → RESET auto-reset cap |
| C6, C7 | 10 µF | 7805 input / output |
| R1 | 10 kΩ | RESET pull-up |
| R2 / LED1 | 330 Ω / LED | pin-13 (PB5) LED |
| R3 / LED2 | 1 kΩ / LED | power LED |
| J1 | 6-pin FTDI header | serial + programming (GND, CTS, VCC, TXD, RXD, DTR) |
| J2 | 2-pin header | 7–12 V DC input |

Board outline: 76.2 × 50.8 mm (3" × 2").

## Notes / caveats (it's a test board)

- **Two possible 5 V sources** — the 7805 output and the FTDI VCC (J1.3) share the
  VCC net, like most hobby breadboard Arduinos. Power from **one** at a time
  (don't apply DC to J2 while the FTDI is also powering VCC).
- GPIO (PD2–7, PB0–4, PC0–5, AREF) are left unconnected — a minimal board, no
  breakout headers. Add headers if you want to use the I/O.
