# backplane — KiCad (ROUTED)

The P8X **backplane** (the passive bus motherboard) as a KiCad 4-layer board,
generated by `generators/gen_backplane.py` from the `bps`/`bpn` structure in
`gen_eagle.py`: **eight** DIN41612 **female** vertical sockets in one row, power
entry, bulk + per-slot decoupling caps, the wired-OR pull-ups, GND (In1) and VCC
(In2) planes, and the full parallel-bus netlist.

**Status: placed + routed + verified (PASS).** 262 × 128 mm, 8 slots on a 28 mm
pitch, left-justified; power/pull-up/termination parts on the right. Routed with
Freerouting and checked by `generators/check_card.sh` (0 blocking DRC, 0
unconnected, keepout + fab clean).

Two design choices made the dense parallel bus routable (see the git history and
`gen_backplane.py` comments for the full story):

- **8 slots, not 10.** Every inter-slot channel carries all ~96 bus nets, so slot
  count is not the main routing lever — but two fewer hops per net helps, and 8
  slots is ample for the active cards (control, regbank, ALU, memory, peripheral,
  + headroom). `NSLOT` lives in `gen_eagle.py`.
- **0.13 mm clearance** (≈5 mil, a standard fab tier) on the backplane only, set on
  the default netclass. This is the real lever: at 0.2 mm the router left 11–18
  hops unrouted, 0.15 mm got it to 1–2, 0.13 mm routes the whole bus. The bus track
  stays 0.2 mm; only the spacing tightens. **The rule ships in
  `p8x-backplane.kicad_pro`, which must stay committed beside the board** so DRC
  and the fab see 0.13 mm.

Mounting holes use **nylon screws** (or none): the DIN mounting-hole copper keepout
is 2.0 mm here (just clears the 2.85 mm hole), not the 4.0 mm metal-screw ring the
plug-in cards use — the bus is too dense for 4 mm rings.
