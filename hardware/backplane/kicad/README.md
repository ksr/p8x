# backplane — KiCad (PLACED, not routed)

The P8X 10-slot **backplane** as a KiCad 4-layer board, generated by
`generators/gen_backplane.py` from the `bps`/`bpn` structure in `gen_eagle.py`:
ten DIN41612 **female** vertical sockets (2 rows of 5), power entry, bulk +
per-slot decoupling caps, the wired-OR pull-ups, GND (In1) and VCC (In2) planes,
and the full parallel-bus netlist.

**Status: placed + netlisted + planes, NOT routed.** A 10×96-pin parallel bus over
a ~560×320 mm board is a large routing job (each bus signal is a comb across all
ten slots); it is left as a follow-up (hand-route, or a dedicated long Freerouting
pass) rather than auto-routed tonight. The sockets, power, caps, netlist and planes
are all in place as a starting point. GENERATORS ARE CANON — edit
`gen_backplane.py` and re-run.

Bulk caps / power entry use the closest standard KiCad footprints.
