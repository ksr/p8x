# docs/reference

`pg640a.pdf`, the Matrox PG-640A programmer's manual that the P8X graphics language
is modelled on, was here until 2026-11-20. It is third-party, so it is kept out of
this public repository, at the same path in the private
`../private-resources/p8x/docs/reference/pg640a.pdf`. The docs, `emulator/p8xemu.c`
and the `gl` and `house` man pages still name it by this path.
See [hardware/reference/README.md](../../hardware/reference/README.md).
