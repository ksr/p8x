Multi-session effort to make the P8X window manager RESIDENT (so launching an app doesn't destroy the desktop) and give windows real terminal I/O. See [[project_p8x_gfx_clib]] and docs/p8x-wm-design.md.

**Two WM implementations exist:** `os/commands/desk.c` = the standalone 35KB C GUI shipped on the card today (WM + apps share one TPA; launching an app destroys desk). `os/wmkernel_body.asm` = the RESIDENT kernel (hand asm), now FOLDED INTO THE OS IMAGE (`.include`d at the end of p8xos.asm) and reached via OS syscalls right after SYS_EXEC: $2027 SYS_WKINIT, $202A SYS_WKOPEN, $202D SYS_WKREPAINT, $2030 SYS_WKRUN, $2033 SYS_WKSAVE, $2036 SYS_WKLOAD. No load step, resident from boot. The 5 `emulator/test/wm_*_test.sh` (kernel/events/mouse/launch/switch) pass via syscalls. NO separate WMBASE any more (anchor removed from memmap); `os/wmkernel.asm` harness + `wm_reside_test` RETIRED.

Ring code is fully symbolic (`#HISTN-1` mask, `#>HISTRING`, HSLOT hi=>HISTRING+slot>>2) so zero shell code changed. **Then: per-window tty/pty (the `dir`-in-a-window problem).** The OS already has the seed: `SYS_PUTC`/`OUTCH` ($2009) routes stdout to console-or-file via REDIRF; `< file` (INMODE), pipes (PIPEF, file-backed/sequential). Plan: generalize OUTCH's sink to also be "a window's text buffer" → text commands (dir/cat/wc) render IN a window with ZERO command changes. NO true concurrency needed: switching is the user's EXPLICIT focus change, only at the desktop between commands (a command runs foreground-to-completion; can't switch mid-command). Per-window state carried in the window record: cwd(48B)+line buf(64B)+scrollback(~140B) ≈ 250B/window; SHARE the 2KB history ring + PATH/resolver. The shell is BUILT INTO the OS (SHELL: loop, not a bash/csh binary); `cd/mkdir/rmdir` are builtins, `dir/cat/pwd` are external /bin binaries (de-built-in'd). Requires the resident WM (control must return to it after a command).

**Boot flow MUST stay:** monitor → B → serial-terminal shell (fd0/1/2 = /dev/tty), GUI opt-in via `desk` command (windows = /dev/pty0..N on the card). User was explicit on this.
