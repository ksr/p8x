Y1/OS (YACC1-D `os/`, plan `docs/system/OS-PLAN.md`, ABI `firmware/abi/README.md`). Decided 2026-09-22 with Ken: CF card
in I/O space on TWO ports (P8 = ATA register-select latch, P9 = data), video v2 will put the 6845 on PA/PB, map variant A
(video $D000, TPA $5000-$CFFF, OS at $1000 from LBA 1.., ROM $F000 only + BASIC still at $E000 for now), ROM holds only
sectors (CP/M style), P8XFS v2 byte-identical (tools/p8xfs.py = a FORK of the P8X tool), kernel in C with y1cc.
**Ken 2026-09-22: Y1/OS and the commands copied over are NOT kept in sync with P8X after the split.**
Done (evening 2026-09-22, emulators only): software/cfmodel.h shared by both emulators (`-c disk.img`); monitor.asm: T-tests
removed, CF driver (cfinit/cfread/cfwrite bounded polls, R7 buffer +512, R6 clobbered), `O` boot command (LBA 0 'P8'/OSCNT,
LBA 1.. -> $1000, JSRUR), vectors CFINIT $FFEC CFREAD $FFF0 CFWRITE $FFF4 CONST $FFF8, vars CFLBA0..2 $0F10, ARGBUF $0F40;
y1cc builtins call(addr) (JSRUR) and argstr(); os/y1os.c v0 (5.1K, 10 sectors): dir/cd/pwd/cat/load/run/help/exit +
implicit /BIN/NAME (upper-cased) with args; os/commands hello/echo/wc; os/Makefile builds disk.img; tests/os/run.py replays
basic.session on both emulators (CR LF in transcripts: read with newline='').
Gotchas found: y1cc multi-declarator bug (`char *a, b` gave b pointer depth) fixed; the interpreter needs `-l N` for code
that never HALTs; 1,111 bytes free in the monitor ROM below the ISR at $FF90.
Next: write support (save/del/mkdir/pack/format/fsck), a file API jump table for programs, port P8X commands (recursion-free),
BASIC as /BIN/BASIC, the CF card in KiCad + bench test, video v2 + PS/2.
